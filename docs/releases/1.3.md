# 1.3

- Usage keeps updating after you quit the app. A small background helper starts at login and checks accounts every three minutes, without a Dock or menu bar icon.
- Settings shows background update status and links to macOS Login Items.
- Account connections recover when the helper restarts, and old Codex workers are cleaned up.
- The main window shows segmented reset countdowns for each usage window.

Requires macOS and Codex CLI. Quit the app and replace it in Applications; account connections are preserved. If macOS asks, allow Codex Usage Viewer under **System Settings → General → Login Items & Extensions**. macOS controls widget refresh timing; missing, stale, or expired limits remain unknown.
