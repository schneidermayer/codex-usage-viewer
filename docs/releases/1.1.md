Codex Usage Viewer 1.1 makes account identity clearer in the weekly widgets.

- Medium widgets show the subscription type beside the seven-day reset bar, replacing “Reset in.”
- Small widgets mark the account logged in to local Codex with a computer icon instead of a colored dot.
- Release builds display **1.1** in the main window and standard Quit command. Subsequent development builds append the number of commits since the release tag.

Requires macOS 27 and a separately installed Codex CLI. The app must remain running to fetch updates; macOS controls widget refresh timing.

Download the ZIP, quit the previous version, and replace **Codex Usage Viewer.app** in Applications. Your three account connections are preserved. The app is signed, notarized, and stapled, with Apple silicon and Intel binaries. `SHA256SUMS.txt` contains the download checksum.
