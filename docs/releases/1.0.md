Codex Usage Viewer 1.0 is a native macOS 27 app for viewing Codex limits across three accounts.

- Full account names with subscription type and a separate **Logged In** badge for local Codex.
- A compact Liquid Glass dashboard with session and weekly limits.
- Weekly-only desktop widgets with seven-day reset bars and numeric countdowns.
- No menu bar tray icon.
- Version **1.0** in the main window and standard Quit command; subsequent builds count commits since the release tag.

Requires macOS 27 and a separately installed Codex CLI. Sign in to each account using its matching Chrome profile. The app must remain running to fetch updates; macOS controls widget refresh timing.

Download the ZIP, move **Codex Usage Viewer.app** to Applications, and open it. The app is signed, notarized, and stapled. `SHA256SUMS.txt` contains the download checksum.
